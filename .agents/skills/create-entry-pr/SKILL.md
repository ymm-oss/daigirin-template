# 参加表明 PR の作成

進捗管理のため、参加者は空コミットのドラフト PR で参加を表明する。このスキルでは、ローカルで原稿を書く環境を用意しなくても、GitHub API 経由で参加表明 PR を作成する。

## 手順

1. `gh auth status` で GitHub CLI にログイン済みか確認する。未ログインなら `gh auth login` の実行をユーザーに依頼して止まる。
2. `gh api user --jq .login` で、ユーザーの GitHub ID を取得する。
3. ユーザーに次の 2 点を確認する。依頼文にすでに含まれていれば、確認を省略する。
   - 表示名（任意。著者名やペンネームなど）
   - ひとこと（任意。書きたいテーマなど）
4. 次のコマンドで PR を作成する。値が空の引数は省略する。

   ```shell
   bash .github/scripts/create-entry-pr.sh --name "<表示名>" --message "<ひとこと>"
   ```

   対象リポジトリはカレントディレクトリのリポジトリになる。別のリポジトリを対象にする場合は `--repo <owner/repo>` を付ける。

5. 出力された PR の URL をユーザーに伝える。

一人で複数の記事を書く場合は、記事ごとに参加表明 PR を作成する。同じ参加者の PR がすでにあっても、新しい PR を作成する。

## 作成される PR

- ブランチ: `entry/<GitHub ID>-<日時>`（例: `entry/alice-20261019-171230`。デフォルトブランチから作成した空コミットのみ）
- タイトル: `[エントリー] <表示名> (@<GitHub ID>)`
- 本文: 参加表明であることと、ひとこと
- ドラフト PR として作成し、担当者にユーザー本人を設定する

## うまくいかないとき

- 対象リポジトリへの書き込み権限がないと、ブランチを作成できない。権限がない場合は、リポジトリの管理者に依頼するよう伝える。
- AI エージェントを使えない参加者には、GitHub の Actions タブから「Create Entry Pull-Request」ワークフローを実行する方法を案内する。
